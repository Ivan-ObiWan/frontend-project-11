## О проекте

**RSS** – специализированный формат, предназначенный для описания лент новостей, анонсов статей и других материалов. Это наиболее простой способ для сайтов (обычно, блогов) дать возможность пользователям подписываться на изменения. Для этого используются специальные сервисы, называемые **RSS-агрегаторами**.

**RSS Агрегатор** – сервис для агрегации RSS-потоков, с помощью которых удобно читать разнообразные источники, например, блоги. Он позволяет:
- Добавлять неограниченное количество RSS-лент
- Автоматически обновлять ленты и добавлять новые записи в общий поток
- Отмечать прочитанные посты
- Просматривать содержимое постов в модальном окне
